# Retained experiment stop attempts

Permanent backing and module lifetime prevent reclamation. They do not skip
genuine stop attempts. This isolated successor replaces only the retained stop
branch; the ordinary release path remains unchanged.

The real non-destructive original GSP shutdown protocol runs before first-record
closing or seal. Original return, ExitReady, exact owner identity and the selected
actual lock observation are prerequisites for hardware calls and CPU joins.
Original lock ownership is observed again after protocol and checked disable,
because those operations can acquire locks themselves. Failed clock, commit or
protocol outcomes preserve their real first cause while independent safe CPU
stop endpoints are still attempted. Each endpoint retains its own checks.

No Context or transport destruction, allocation free, IOVA unmap, destructive
phase, whole-stop receipt, or PM acknowledgement is granted. A completed protocol
still retains all backing, callback owners and module text until reboot.

The plain C diagnostic header keeps original NVIDIA types behind one separately
compiled original-C bridge. CPU controls execute the actual retained dispatch
prefix/helper and complete Services TU with explicit endpoint fault seams. They
do not execute original RM, GSP, Darwin or hardware. Separate SDK cross builds
check the actual complete Bootstrap, Power, Services and original-C bridge TUs.
