# Live original ABI requirements

The strict exploratory cross link retained all 25 typed original roots and the
actual project modules. It allowed only independently compiled SDK imports,
used dead stripping, and refused unresolved private symbols. It found 27 live
legacy callbacks after the seven platform callbacks were supplied.

The evidence directory records the full linker diagnostic, exact declarations
and referencing original callers. This is Linux `ld64.lld` MH_BUNDLE evidence
from explicitly identified cross-compiled inputs. It is not native Apple link,
kernel-load, GPU-operation or runtime-admission evidence. The authoritative
workflow must freshly compile and strictly link its complete source profile.

The port-I/O subdirectory supplies six real x86 operations through the pinned
Apple SDK `architecture/i386/pio.h` interface. Darwin's write interface takes
`(port, value)`; the callbacks preserve NVIDIA's `(address, value)` ABI and the
hardware's 16-bit port selection. They do not return invented reads or silently
discard writes. Their actual machine code must match independent typed SDK
wrappers and contain the corresponding IN/OUT instructions with no imports.

The checker only compiles and inspects code. It never executes port instructions.
The source requires the explicit `S540_NVIDIA_DARWIN_PORT_IO=1` profile, real
original private namespace, x86-64 Unix declarations and kernel compilation.
Those source checks do not grant authority to enter the original GPU driver.

Existing `prospective-uvm-disabled/S540ProspectiveUvmDisabled.c` supplies the
three UVM callbacks for its explicitly selected no-UVM profile. It must replace
missing implementations in the same image; this package does not duplicate it.

The fixed composer `--live-abi-closure` profile includes the reviewed UVM,
mapping, control-state and live-platform sources, requires all four earlier
fixed profiles plus retained-backend and global-epoch successors, and produces
60 project translation units. It also composes the exact three original
OS-event constructor/notification guards before first-transaction overlays.
Those guards and the nonprimary emulator receive their required definitions
only on their individual original translation units. The real port-I/O module
remains isolated and is not selected by this profile.

The nonprimary-x86 successor preserves the exact original nonprimary-VGA
`NV_OK` early return. A primary adapter receives `NV_ERR_NOT_SUPPORTED` before
emulator allocation, legacy-memory mapping or I/O callback publication. It
does not supply a fake emulator. Actual baseline/proposed bodies and the real
original caller pass 26 controls in each ordinary and sanitizer variant using
complete original types. The complete modified translation unit compiles and
has none of the six port callbacks or `nv_get_updated_emu_seg` imports. An
independent strict dead-strip cross link correspondingly reduces the required
legacy callbacks from 27 to 20. The verified Intel-console and excluded-NVIDIA
console binding remains a separate operational-owner requirement.

The complete 60 project units and five changed original translation units
compile as genuine x86-64 Mach-O with the actual source/header companion.
The subsequent strict exploratory link of 1,163 objects has zero private
unresolved callbacks, with neither `rm_ioctl` nor the local `allocate_os_event`
atom retained. Its unchanged 445 SDK-public import exceptions derive from
independent references; no private exception or stub was added. The probe
uses MH_BUNDLE chained fixups because classic user-mode lazy binding otherwise
requires a linker-created `dyld_stub_binder`, which is not a source callback.

The full input manifest records that 1,095 original objects and three firmware
or wrapper objects came from prior cross compilations. Five original objects
and all 60 project objects were freshly compiled from the new composition.
This mixed-checkpoint probe does not establish a complete native source build,
kernel-extension layout, entry permission or installable package. Native CI
must freshly compile all 1,100 original units against the composed headers,
then perform its strict Apple kext link and independent admission checks.
All source and runtime gates remain closed in this development composition.
