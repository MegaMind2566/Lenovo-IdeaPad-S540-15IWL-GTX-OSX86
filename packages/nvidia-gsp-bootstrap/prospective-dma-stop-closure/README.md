This isolated successor checks the real BME field before and after its config
write, and replaces the selected TU102 transactions-pending poll with a genuine
cancellation-bound loop. Every actual PCI endpoint holds a tracked commit until
it returns. A zero TP observation is never a posted-write or whole-DMA-stop
receipt. All-ones reads, missing handles, revocation and every timeout status
remain failures.

The cleanup-mask observer additionally accepts the real clean CLOSING boundary;
sticky RETAINED identity remains separate from ordinary original entry. No
status is reset, no receipt is manufactured, and no storage is reclaimed.

Run `check.py` against the exact shutdown parent for CPU controls and
`check_sdk.py` for five complete cross-compiled original/project units. These
checks do not replace native image validation or the Lenovo test.
