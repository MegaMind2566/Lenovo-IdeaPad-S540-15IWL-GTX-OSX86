# Isolated first-transaction record

This package is prospective. It changes no default build, approved source
profile, callback policy, hardware state or power admission gate.

The strong C record owns one immutable pre-global owner/generation, then attaches
one exact `nv_state` cancellation anchor. Work and direct timer tickets are
reserved only at genuine guarded service admission; entry binds the actual
worker thread. Original-wrapper return and later service-action return are
separate observations. An unlocked original exit is recorded even after failure,
and its return status preserves the first failure over a later `NV_OK`. Genuine consumed tickets settle even after first failure;
the transaction remains permanently retained. There is no reset, fake completion,
blanket drop, release receipt or retry API.

`ObserveServiceRefusal` atomically orders actual source failures against physical
Host-free permits. It also observes the BeginOwner reservation window. Source
producers must publish their lifetime counters and invoke the hook before
returning to any inner free. The owner publication never overwrites a concurrent
retained phase. Host allocation identities are captured before global RM starts,
and prior original allocations are rejected by actual Host preflight.

`Seal` and `BeginDestructive` perform real service proof and counter reads outside
original locks. Under original/registry locks, predestruction checks use bounded
record state; event destruction additionally pulls the genuine cancellation stage
without re-locking the timer guard. Unknown objects and failed original-allocation
triples have fixed retained evidence slots. Capacity exhaustion refuses cleanup.

The participant implementation and minimal ABI headers are local under `deps/`.
Their provenance records exact historical hashes and include-only rewrites.
Historical participant66 files and the production cancellation implementation were
not modified. The retained cancellation anchor is deliberately never released.

## Remaining boundaries

- The packaged original policy supplies only the actual nano WORK row. It supplies
  no OWNER/EVENT authorization, so general timer policy remains refused.
- Original RM-semaphore functions provide no real ownership receipt. The original
  bridge keeps this gate closed. API/GPU probes alone cannot substitute for it.
- Work metadata does not independently attest `gpuInstance` against the attached
  device. The tested nano source chain supplies the selected GPU; generic producer
  coverage requires its own reviewed binding proof.
- An `originalInFlight` bit retained after an unverified exit means an unverified
  call reference, not proof that a wrapper is physically still executing. Failure
  never promotes that state to a valid return/seal.
- Pre-global wrapper retention, all producer dispositions, constructor rollback,
  scheduling bounds, actual GSP/hardware stop and DMA/text release remain separate
  gates. These CPU tests issue no hardware receipt and establish no macOS kernel
  execution or laptop-test admission.
