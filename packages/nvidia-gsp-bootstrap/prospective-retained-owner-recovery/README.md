# Reconstructed permanent retained Owner

This new source successor reconstructs the retained Owner flow after the scratch
workspace reset. It is independently identified by the files and hashes in this
directory. Previous uncommitted binaries, source hashes and execution results
were lost and are not validation for these bytes.

The recovered remote baseline still closes original entry. This successor does
not join the closed idle package, change its loader, clear a readiness gate,
authorize a DMA-stop receipt, or authorize physical release. Its builder refuses
until the actual IRQ participant profile has been rebuilt and composed alongside
the retained Host/backend, global epoch, control-state and shutdown profiles.
Declarations or profile Booleans cannot replace missing concrete source APIs.

`prepare.transforms(values)` takes exactly the Bootstrap.cpp, Bootstrap.hpp and
Context.c paths listed in `INPUTS`. Apply it after the final Context first-
transaction and IRQ overlays. Copy `S540NvidiaRetainedOwner.h` into the relative
path given by `PRIVATE_HEADER`. It adds three typed Context exports, no new
translation unit and no compile definition:

- `s540GspContextStopRetainedServices`
- `s540GspContextRunRetainedShutdownProtocol`
- `s540GspContextReadRetainedShutdown`

The real persistent worker initializes Host, latches permanent retention before
its BeginOwner attempt, obtains the actual master generation and prepares the
real control state while nv remains unbound. Context construction captures that
generation before Host allocation. A partial construction returns its retained
pointer instead of invoking legacy destruction.

Cancellation binds and enters its operation before the DeviceServices binding.
Immediately after that binding, the real Session takes its hardware DMA lifetime
before firmware copies, global construction or private/GPU initialization. The
Host firmware copies and Store remain allocated. The original OSINIT failure
hook retains its actual firmware lease handles during the original attempt;
Host copy pointers are never passed as substitute lease handles.

Initialize calls the existing global lifecycle, retaining its closed kernel
entry gate. Context binding is permitted only after the real epoch has returned
and validated successfully with nv still NULL and the exact retained generation.
ContextBind alone binds the strong nv and its real queue/timer services once,
before private initialization and GPU attach. Control adapter binding follows,
then private preparation, then the fixed IRQ adapter. The existing adapter gate
constant is unchanged and remains before the adapter call.

After any permanent Owner attempt or DMA hold, failure and stop avoid legacy
cleanup. Actual interrupt stop must succeed before actual source sealing. Only
an actually initialized adapter can attempt the typed shutdown protocol, after
a genuine drained-IRQ query. Every failure retains the owner. Even successful
protocol completion does not Finish/Unbind cancellation, drain retirement for
physical release, shut down global/Store state, acknowledge PM, join/destroy the
worker, or free backing. Context destruction and private-state release refuse a
retained owner. No caller flag declares IRQ or DMA quiescence.

Fresh `check_source.py` controls apply this overlay to restored actual Bootstrap
and the actual first-transaction Context generator. They verify source anchors,
ordering, unchanged gates and refusal of absent dependencies. They produce
reviewable transformed source under `build/` and preserve all input files.
These are structural source controls only: native execution and kernel
compilation have not been rerun. The complete actual Owner CPU controls, fatal
sanitizers, pinned-SDK whole-TU compilation and composition/link validation must
be rebuilt after the genuine IRQ successor is available. No GPU, PM or original
core success is claimed.
