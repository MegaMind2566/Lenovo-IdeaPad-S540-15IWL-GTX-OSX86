# Exact native retained-experiment package

`package_verified_plan` accepts the current replay callback and an independently supplied native image report SHA256. It requires actual Intel Apple execution before any package output. It rechecks the entire current native compile matrix, source/command/dependency captures, compiler/SDK/helper bindings, fresh preliminary/final machine-code graph inputs, immutable native budget, exact SDK references,25 original roots, module-runtime bytes, three metaclasses, final private closure and public KPI export provenance.

The packager builds the userspace client from the actual composed source with image-bound source/policy/native-code digests. It signs the real kext and client, then independently checks that signing changed only allowed signature/LINKEDIT metadata and preserved code, data, import/export/loader pointers, firmware, profile and Kmod semantics. It never loads code or changes security settings.

The B5 output container holds `S540ExperimentalInitRetained/`, `S540ExperimentalInitRetained-B5.zip`, an outer copy of the attestation and package digests. The payload has the signed bundle/client, explicit target-test script, full file manifest, report evidence, firmware notice and corresponding sources. The source archive includes every materialized original/project file, recipe inputs and pinned SDK, preserving actual executable modes. Real `unzip` roundtrip controls restore the inventoried original/project bytes and modes, including executable original files and pinned SDK files; removing the original legal notice is refused.

B5 classifies the optional I/O BAR in slot 5 separately from memory BARs and does not map it as MMIO. The three verified MMIO BAR requirements and existing mapping checks remain in force. It accepts normal PCIe endpoints (type 0) and legacy PCIe endpoints (type 1), including the authentic `IOPCIExpressCapabilities=0x12` value. Other device/port types remain refused. This classification uses the already-read flags and adds no PCI access. The physical B5 test on the Lenovo remains pending.

The target script verifies the independent attestation and every payload file before loading a fresh root:wheel copy. It distinguishes loader admission, control readiness, request/RPC results and actual stop diagnostics. It issues no unload; a load accepted or left uncertain requires reboot under the test policy. Original-visible or uncertain resources remain retained, with checked pre-original cleanup permitted. Successful packaging does not establish target loading, RM/GSP initialization or acceleration; the actual Lenovo report remains necessary.
