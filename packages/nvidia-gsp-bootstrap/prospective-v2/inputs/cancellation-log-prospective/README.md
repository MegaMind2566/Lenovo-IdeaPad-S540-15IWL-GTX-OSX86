# Isolated source-body fixtures

Four complete original log bodies are tested with actual strong cancellation state and real local Darwin services. Thirty-seven checks per plain/fatal variant cover revocation, cursor/lock ownership and early optional-log exits. This does not prove the aggregate PM deadline.

Run the parent `check_body_controls.py` CLI; it regenerates the exact bodies from pinned upstream bytes and these patches. No original source tree or executable is stored here.
