# Fine output volume package

Source for the guarded upgrade from the installed S540 VoodooHDA 3.6.9 microphone variant to 3.6.10 with the full analog DAC range. Use the built ZIP; these source launchers do not include the compiled and locked payload.

See [installation, verification and rollback](../../docs/guides/volume-control.md). The old microphone package and its private backup are preserved.
