# v0.1.0 — Initial macOS Tahoe EFI

**Release preparation:** the current EFI snapshot is required before the asset can be published.

OpenCore configuration for the **Lenovo IdeaPad S540-15IWL GTX (81SW)** with Intel Core i7-8565U, UHD 620 and Realtek ALC257. macOS runs from an external Samsung 960 EVO; Windows remains on the internal SSD.

## Working

- macOS Tahoe boot and desktop.
- Intel UHD 620 acceleration with Metal 3.
- Internal Full HD display and brightness slider.
- Startup backlight without the previous black-screen delay.
- Speaker playback, gradual volume control and F1–F3.
- Internal microphone with the S540 input-gain correction.
- Intel Wi-Fi managed through HeliPort.
- Bluetooth headphone playback.
- Webcam, CPU power management and battery detection.
- External Samsung 960 EVO access over USB.

## Not working

- NVIDIA GTX 1650 Max-Q acceleration.
- F11/F12 brightness controls.
- Native macOS Wi-Fi management; use HeliPort.

## Pending

- Touchpad gestures.
- Analog audio jack and Bluetooth microphone.
- HDMI and USB-C video output.
- USB SuperSpeed and connector orientation checks.
- SD card and fingerprint readers.
- Battery runtime, sleep and wake.
- NVIDIA electrical power-off.

## Setup

SMBIOS identity and network credentials must be supplied locally. Machine-specific identifiers will be removed from the release asset.

Audio also requires the VoodooHDA extension in `/Library/Extensions`; copying the EFI alone does not install it. Follow the [audio](../guides/AUDIO-TAHOE.md) and [microphone](../guides/MICROFONO-FIX.md) guides.

Keep a copy of the existing boot configuration before replacing it. The first release will preserve the current configuration rather than apply additional hardware changes.
