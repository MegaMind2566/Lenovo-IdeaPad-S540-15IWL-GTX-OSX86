# v0.1.0 — Initial macOS Tahoe EFI

OpenCore configuration for the **Lenovo IdeaPad S540-15IWL GTX (81SW)** with Intel Core i7-8565U, UHD 620 and Realtek ALC257. macOS runs from an external Samsung 960 EVO; Windows remains on the internal SSD.

## Working

- macOS Tahoe boot and desktop.
- Intel UHD 620 acceleration with Metal 3.
- Internal Full HD display and brightness slider.
- Startup backlight without the previous black-screen delay.
- Speaker playback, gradual volume control and F1–F3.
- Internal microphone with the S540 input-gain correction.
- Intel Wi-Fi managed through HeliPort.
- Bluetooth headphone playback.
- Webcam, CPU power management and battery detection.
- External Samsung 960 EVO access over USB.

## Not working

- NVIDIA GTX 1650 Max-Q acceleration.
- F11/F12 brightness controls.
- Native macOS Wi-Fi management; use HeliPort.

## Pending

## Setup

The ZIP contains the current enabled EFI components and preserves the Intel framebuffer and `-igfxblr` backlight settings. Trial configurations, backups, disabled components, personal SMBIOS identifiers and saved Wi-Fi networks are excluded.

Generate your own **MacBookPro16,2** identity and fill the four `PlatformInfo → Generic` identity fields before booting. Use HeliPort to select your network. The included README explains setup, component hashes and licenses.

The working installation also uses VoodooHDA S540 variant **3.6.9** in `/Library/Extensions` and existing Bluetooth NVRAM state. Copying this EFI does not install either prerequisite. Audio drivers are built separately; the older audio tools require their original rollback state.

Keep the existing working external boot device available while personalizing this EFI. The package does not include macOS or an installer image.
